## 🚀 Featured Projects

### 1. Bank Marketing Classification

A Machine Learning classification project focused on predicting customer responses using banking marketing data.

**Algorithms & Techniques:**
- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- Gradient Descent (GD)
- Stochastic Gradient Descent (SGD)
- Mini-Batch Gradient Descent
- RMSprop & Adam
- Voting Ensemble

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1-Score
- Loss

### 2. Arabic Named Entity Recognition (NER)

An Arabic Natural Language Processing project designed to identify named entities in Arabic text.

**Technologies & Techniques:**
- ANERCorp Dataset
- Arabic Text Processing
- TF-IDF Feature Extraction
- Character N-grams
- Random Forest Classification
- Named Entity Categories: PER, LOC, ORG

### 3. Neural Networks & Optimization Algorithms

An implementation and comparison of different optimization algorithms used for training neural networks.

**Optimizers:**
- Gradient Descent (GD)
- Stochastic Gradient Descent (SGD)
- Mini-Batch Gradient Descent
- RMSprop
- Adam

**Objective:** Compare optimization strategies and evaluate their training performance.

### 4. Car MPG Data Analysis

A Python Data Analysis project exploring vehicle fuel efficiency and identifying patterns in car specifications.

**Technologies & Techniques:**
- Python & Pandas
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Analysis
- MPG Insights
